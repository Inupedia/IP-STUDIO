# IP Studio V1 — 设计说明（Superpowers Spec）

> 日期：2026-10-14
> 状态：从既有产品讨论收敛成开发基线；本文件配合 `docs/product/PRD-v1.md` 使用。
> 需求权威：`docs/product/PRD-v1.md`

## 目标与非目标

目标：让一位 IP 主理人在同一工作室内管理多个原创漫画 IP，复用带版本的角色/场景/画风资产，通过固定品牌模板、可变分镜和 PPT 式编辑器，制作并可恢复地保存漫画；本机 Codex 原生 ImageGen 如可用则直连，不能用时保留在线 ChatGPT 生图回退。

非目标：自研图像模型、付费图像 API 的必选依赖、视频制作、小红书自动发布、多账号数据抓取、多用户协作、任意既有漫画位图无损转分层。

## 已定决定

1. **小而可维护的独立 V1**：暂不 Fork Jellyfish；产品重心不是视频短剧 pipeline。
2. **单工作室、多 IP、单管理员**：每个资产记录 `workspace_id` 和可选归属 `ip_id`；需要跨 IP 时显式共享并保留许可/来源。
3. **模板双层**：BrandTemplateVersion 包含不可在普通编辑模式修改的外框、纸纹、Logo、固定标题样式、装饰和页脚；PanelLayoutTemplate 允许 4/6/8 格、自定义画格；每页绑定冻结品牌版本，内容单独存储。
4. **原始资产可追溯**：角色/画风/品牌/图片均为草案→批准锁定版本。引用到分镜时写入具体 version ID。无法编辑扁平素材内部笔触。
5. **编辑器主数据为 JSON 文档**：浏览器画布与图层树只是状态渲染器；非破坏裁切、Undo/Redo、自动保存、快照、并发 revision 校验。
6. **无字画面 + 独立中文**：ImageGen 只生成无字单格候选画面，文字、气泡、聊天对话与方向由编辑器确定，避免错字和消息颠倒。
7. **Codex 双轨**：先做 `probe_capabilities()` 的真实 PoC，确认本机安装的 App Server / CLI 是否暴露并能实际完成 ImageGen；可用时走本地生成自动入库，否则用提示词/参考图包+粘贴/文件导入；失败不阻塞编辑。
8. **可编辑导出边界**：工程 ZIP 最可编辑；PPTX 原生文本/形状/独立图片可改，但位图内容、复杂裁剪与字体不承诺像素级往返。
9. **控制成本**：不生成模板外框，不因更改台词重绘图片，优先复用被批准资产；记录候选数/复用率，不凭空估算 API 费用。

## 一次创作的完整用户旅程

1. 创建《人间卡顿局》IP，导入并锁定卡仔、噗噜、零零的 CharacterVersion 与 StyleVersion。
2. 创建并批准品牌模板 v1，定义外框、Logo、固定页脚和标题/EP 内容槽。
3. 新建系列、EP02；选择品牌版本及 4/6/8 格布局，在剧本中定义场景、人物与聊天消息。
4. 系统组合“无文字、单画格、固定角色/风格”的提示词和参考图清单。
5. 如果 Codex ImageGen 已通过实际自检，点生成并将真实图片作为 candidate 归档；否则在线 ChatGPT 生图粘贴导入。
6. 在画布拖拽/裁切/替换独立图片层，文本气泡原生可改；保存快照。
7. 一键导出 PNG 图片组、工程 ZIP、分层 PPTX；历史导出与品牌版本不会被后续编辑覆盖。

## 分解为五个可独立验收的子项目

| 阶段 | 可演示交付 | 为什么单独规划 |
|---|---|---|
| 01 | 工程基线、IP/角色/画风/素材入库、稳定版本 | 后面所有能力依赖的权威数据 |
| 02 | 品牌模板与版式、PPT 式画布、可编辑图层 | 核心用户价值，可仅用本地图片验收 |
| 03 | 剧本/分镜、生图任务卡、手动导入闭环 | 无 Codex 也可完成漫画制作 |
| 04 | 本机 Codex 能力探测、ImageGen 条件接入、Patch 审批 | 外部运行环境不确定，单独围栏 |
| 05 | PNG/ZIP/PPTX 导出与 EP01/EP02 端到端验收 | 避免功能看似能用但导出无法编辑 |

## 验证风险

- **角色一致性**：提示词只能帮助减少漂移，标准资产/参考图/人工审核是最终约束，不能承诺像素级一致。
- **模板误改**：品牌层与动态内容层分库并在 API/命令校验，不靠前端隐藏按钮保护。
- **中文**：字体与溢出检测必须覆盖截图与导出，不把中文交给生图渲染。
- **Codex 能力缺失**：无 imagegen tool/权限/会话等情形必须获得可解释错误与人工回退。
- **工程恢复**：ZIP 必须包含素材且验证哈希、schema_version 与引用完整性，防路径穿越。
- **多标签页冲突**：revision 冲突为 409，不能静默后写覆盖。

## 完成定义

PRD 的 AC-01～AC-26 全部得到自动化或可重复人工证据；冻结品牌模板在 EP01/EP02 中保持外框一致；漫画文字及聊天方向正确；所有资产引用可恢复，导出后的工程仍可编辑。
