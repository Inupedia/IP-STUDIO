# IP Studio V1 手动验收 Runbook

前置条件：按 [本地开发与启动](../deployment/local-development.md)启动 API、PostgreSQL 和 Web；使用受控管理员账户登录。此 Runbook 使用本地自建或用户拥有版权的图片，不调用付费图片 API。

## EP01 / EP02 品牌回归

1. 在左侧选中 `人间卡顿局`，进入“漫画工作台”。选择 EP01，确认标题为“在吗？”。
2. 展开“剧本与生图工作流”。编辑剧本及镜头动作，点击“保存为新修订”，再点“从剧本生成分镜卡”。
3. 在 EP01 第一格确认朋友的“在吗？”在左、卡仔的“不在。”在右。
4. 在素材库中选择同 IP 的已批准图片；在画布属性层选中第 2 格图片，用“替换单格图片”替换。保存后确认其他画格和消息没有变化。
5. 在第 4 格文字属性框依次输入 10 条中文，点撤销、重做，再保存。刷新页面，确认最终文字保留。
6. 用 Shift 点击同一画格的多个图层，填水平/垂直位移并执行“整体移动所选图层”；点一次撤销，确认整组恢复，再保存。
7. 选择 EP02。确认标题为“今天又加班”，模板版本 ID 与 EP01 一致，Logo、底色、页脚位置固定。
8. 下载 PPTX。用 PowerPoint、Keynote 或 LibreOffice 打开；按对象分别选中图片、气泡和文字。复杂裁切/字体替代警告按导出面板提示核对。

## ChatGPT Web 人工生图回退

1. 在剧本编辑器建立并保存至少一张分镜卡。
2. 在“生图目标分镜卡”选择目标，点击“准备 ChatGPT Web 生图任务”。
3. 复制冻结提示词；需要参考资产时下载参考包 ZIP。仅在用户自己的 ChatGPT Web 会话中手动生图。
4. 点“我已在 ChatGPT Web 开始生成”，把对应结果拖入或选择 PNG/JPEG/WebP。导入必须绑定任务冻结的 Panel。
5. 确认候选以“待审核”状态进入审核列表，正式画布仍未改变。批准后才加入可复用素材库，再显式替换画格。

## 资产、冲突与长文

- 在素材库选中旧扁平 EP02 PNG，将其作为 `composite_panel` 位图上传并批准；可作为参考图片加入画格。UI 不提供逐笔编辑承诺。
- 在同一单集打开两个标签页。第一个标签保存后，第二个标签再保存应收到 revision 冲突；重新加载后应看到首个标签的内容。
- 在文字图层输入超长中文。画布顶部应显示可能超框提示；缩短内容或调整文本框后再导出。
- 删除被文档、模板或任务引用的素材应被拒绝；删除未引用素材需显式确认。

```bash
bash scripts/verify-v1.sh
```

执行结果以终端退出码和 [V1 Release Checklist](V1-release-checklist.md) 为准。自动化 E2E 使用固定 fixture 和 API route mock；它不替代真实 PostgreSQL/Blob 恢复演练或 Codex 原生任务运行。
